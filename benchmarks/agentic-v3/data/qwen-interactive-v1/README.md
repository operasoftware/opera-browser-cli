# qwen-interactive-v1

Balanced agentic-v3 matrix: strict and open arms, three repeats, upstream `main` versus compact-v3 `head`.

- `results/`: 72 direct Responses API agent envelopes.
- `logs/`: per-cell browser-CLI TSV and captured output logs.
- `SHA256SUMS`: integrity manifest for all retained result and log files.

The direct driver used a 50-turn ceiling and capped each tool result fed to the model at 8,000 characters. See the cross-model whitepaper for model identity, pricing status, and interpretation.
