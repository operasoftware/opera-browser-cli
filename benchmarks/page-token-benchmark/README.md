# Page Token Benchmark

Measures the token cost of `opera-browser-cli` output across different flag combinations, using 50 static web pages as input.

## What it measures

Every browser agent task sends page content to an LLM. The output size (in tokens) directly affects cost and context window usage. This benchmark answers:

- How many tokens does each CLI flag combination produce per page?
- How much does `--raw` increase token count vs the default compact output?
- How much does `--full` increase token count vs the above-the-fold default?

### Conditions

| ID | Flags | Description |
|----|-------|-------------|
| `opera-compact` | _(none)_ | Opera compact snapshot, above-the-fold |
| `opera-compact-full` | `--full` | Opera compact snapshot, full page |
| `opera-raw` | `--raw` | Opera uncompressed MCP output, above-the-fold |
| `opera-raw-full` | `--raw --full` | Opera uncompressed MCP output, full page |
| `mcp-raw` | _(bridge)_ | Raw `take_snapshot` via bridge HTTP API |
| `axi` | _(none)_ | chrome-devtools-axi, above-the-fold |
| `axi-full` | `--full` | chrome-devtools-axi, full page |

### Pages

50 static pages across five domains (10 each): Wikipedia articles, GitHub repository homepages, MDN Web Docs reference pages, Python standard-library docs, and RFC Editor specifications. Each page is snapshotted fresh for every condition run.

### Token counting

Uses [tiktoken](https://github.com/openai/tiktoken). Default model: `gpt-5.5` (falls back to `o200k_base` encoding if the model is not recognised by tiktoken). Override with `--model`.

## Setup

Requirements: Python 3.11+, `opera-browser-cli` in PATH, Opera/Chrome browser open.

```sh
cd benchmarks
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Running

All commands run from `benchmarks/` with the venv active.

### Sanity check (1 condition, 1 URL)

```sh
python page-token-benchmark/src/run_benchmark.py --conditions default --urls 0
```

### Single condition

```sh
python page-token-benchmark/src/run_benchmark.py --conditions default
```

### All conditions

```sh
python page-token-benchmark/src/run_benchmark.py
```

### Generate report

```sh
PYTHONPATH=. python page-token-benchmark/src/report.py
# → page-token-benchmark/results/report.md
```

## Linting & formatting

Dev tools are shared at the `benchmarks/` level. From `benchmarks/`:

```sh
pip install -r requirements-dev.txt
make check   # format-check + lint + typecheck — matches CI
```

## Source layout

```
src/
├── run_benchmark.py   # entry point — CLI arg parsing, outer loop, JSONL writing
├── cli_runner.py      # subprocess wrapper for opera-browser-cli open
└── report.py          # reads results/*.jsonl and writes results/report.md

config/
├── urls.yaml          # 50 static page URLs
├── conditions.yaml    # CLI flag combinations to test
└── settings.yaml      # tiktoken model and output directory

shared/                # (at benchmarks/ level)
└── token_counter.py   # tiktoken wrapper used by this benchmark
```

## CLI reference

```
python page-token-benchmark/src/run_benchmark.py [options]

  --conditions   Comma-separated condition IDs (default: all four)
  --urls         Comma-separated 0-based URL indices (default: all 50)
  --model        tiktoken model override (default: gpt-5.5)
```

## Results layout

```
results/
├── opera-compact.jsonl
├── opera-compact-full.jsonl
├── opera-raw.jsonl
├── opera-raw-full.jsonl
├── mcp-raw.jsonl
├── axi.jsonl
├── axi-full.jsonl
└── report.md          # generated by report.py
```

Each JSONL record contains:

```json
{
  "url": "https://...",
  "condition": "default",
  "tokens": 1234,
  "chars": 5678,
  "returncode": 0,
  "wall_seconds": 1.23,
  "error": null
}
```
